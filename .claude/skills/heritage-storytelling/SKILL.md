# Heritage Storytelling

Sección "La Crónica de la Prenda": contexto histórico, nivel de rareza
o anécdota del modelo, para que cada camiseta se sienta como una pieza
de archivo, no un SKU más.

## Estado actual (2026): diferida, sin implementar

No existe un dato real de historia/rareza/anécdota por producto en el
catálogo (3670+ productos) -- ni un campo estructurado, ni contenido
curado a mano. Implementar esto con texto inventado por producto sería
fabricar afirmaciones históricas no verificables (riesgo real de
desinformación), así que se dejó afuera del rediseño de 2026-08 hasta
tener una fuente de datos real.

## Cuándo retomarla

Solo con una de estas dos bases:
- Contenido curado a mano para un subconjunto de productos realmente
  icónicos (no los 3670+), o
- Una fuente de datos externa verificable (no generación libre) que
  aporte hechos reales por modelo/temporada.

Hasta entonces, no completar esta sección con texto genérico
disfrazado de hecho histórico específico.
